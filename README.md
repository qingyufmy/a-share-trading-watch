# A-share Trading Watch

面向 A 股盘前计划、竞价评估、盘中信号、模拟交易与盘后复盘的一体化研究和盯盘系统。

## 主要模块

- 盘前标的分类、交易计划与数据质量检查
- 集合竞价路径采集和评估
- 盘中行情监控、策略信号与风险控制
- 情绪龙头、520 与五日线趋势策略研究
- 模拟账户、收盘持仓表现与盘后复盘
- 每日观察池前十反向核查和影子研究
- 本地 Web 工作台与飞书消息通知

## 仓库边界

本仓库保存源码、测试、研究脚本、配置结构和交付文档。本机运行数据不进入版本控制，包括行情缓存、日志、数据库、模拟账户、报告输出、浏览器痕迹、虚拟环境和发布备份。

实际运行目录、凭据和通知地址应通过本机环境独立配置，不应提交到仓库。
